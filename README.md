# Hand-Sign-Language-Recognition-Predictive-Text-System

Sign Language Recognition

A real-time sign language recognition application developed as part of the AI Lab: Computer Vision and Natural Language Processing course at Sapienza University of Rome.

The project combines computer vision, machine learning, and natural language processing to recognize sign language gestures and convert them into written text in real time.

Overview

The application analyzes visual input from a camera and recognizes sign language gestures performed by the user.

The recognized signs are processed and converted into text, providing a simple communication interface between sign language gestures and written language.

The project focuses on the application of computer vision and machine learning techniques to a real-world communication problem.

Main Features
Real-time sign language gesture recognition
Camera-based visual input
Machine learning-based gesture classification
Conversion of recognized signs into written text
Continuous processing of the user's gestures
Integration of computer vision and NLP techniques
Technologies
Python
Computer Vision

Project Structure

The project is organized into separate components for:

Visual input and image processing
Sign language recognition
Machine learning model processing
Text generation and processing
Application interface
How It Works

The recognition pipeline can be summarized as:

Camera Input
     ↓
Image Processing
     ↓
Gesture Recognition
     ↓
Machine Learning Model
     ↓
Recognized Sign
     ↓
Text Output

The system continuously processes the camera input, identifies the performed sign, and produces the corresponding written output.
